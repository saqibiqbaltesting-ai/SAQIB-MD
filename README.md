# SAQIB-MD 🤖

Attitude King ka apna WhatsApp bot — Baileys based, pairing code connect, 364+ commands.

## Chalane ka tareeqa (Windows)

1. **Node.js install karo** (agar nahi hy): https://nodejs.org → LTS download → install
2. Is folder me terminal kholo (folder me `cmd` likh ke Enter)
3. `npm install` chalao (sirf pehli dafa)
4. `.env` file banao (`.env.example` ki copy) aur apna number dalo:
   ```
   OWNER_NAME=Attitude King
   OWNER_NUMBER=92xxxxxxxxxx
   GEMINI_API_KEY=tumhari_gemini_key
   ```
5. `npm start` chalao → pairing code screen par aayega
6. WhatsApp → **Linked devices** → **Link with phone number instead** → code dalo
7. Done! Ab kisi bhi chat me `.menu` likho 🔥

## AI commands ke liye key

`.ai`, `.gpt4`, `.gemini`, `.grok` waghera sab Gemini API par chalti hain.
Free key: https://aistudio.google.com/apikey → copy → `.env` me `GEMINI_API_KEY=` me dalo.
